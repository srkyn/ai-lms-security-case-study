# Redaction Notes

The source assessment contained confidential and privacy-sensitive material. This repository is a public-safe derivative, not a copy of the original report.

## Removed

- The original confidential PDF
- Screenshots from the live environment
- Student names, email addresses, cohort identifiers, and account details
- Live LMS URLs, course IDs, API paths, and exact hostnames
- Internal tool schemas and prompt/configuration dumps
- External listener URLs and mock-server details
- Names and filenames of personal documents found in the knowledge base
- Copy-ready prompt strings and exploit payloads
- Any CDN links, file paths, IDs, tokens, or private infrastructure hints

## Kept

- The finding themes
- Severity levels
- Defensive reasoning
- Attack-chain structure at a conceptual level
- Remediation guidance
- Lessons learned for AI application security

## Redaction Philosophy

The goal is to preserve the value of the work without increasing risk.

Useful public security writing should help defenders recognize patterns, fix systems, and ask better questions. It should not expose private people, live targets, or step-by-step instructions for replaying an issue.
