# Security Policy

This repository is a sanitized public case study. It intentionally excludes
target-specific details and exploit instructions.

## Reporting Concerns

If you believe this repository accidentally exposes sensitive information, open a
minimal GitHub issue or contact the repository owner privately. Do not include
private data or exploit details in a public issue.

## Scope

In scope:

- Accidental disclosure of target-specific information
- Public text that could identify the assessed environment
- Public text that could reasonably function as an exploit guide

Out of scope:

- Requests for the original confidential report
- Requests for exploit prompts, target URLs, screenshots, or private evidence
- Claims about the current security posture of any specific institution or vendor
